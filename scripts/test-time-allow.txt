# The time guard's allowlist. scripts/test-time-guard.sh prints a WARN line when a package takes more than 60s or a
# single test more than 5s. It never fails CI. A line here sets the ceiling past which that entry warns.
#
#   <package, Pkg.TestName or Pkg.*>  <ceiling in seconds>  <reason, one line>
#
# A package is its path under the module (internal/store). Pkg.* covers every test of the package. A subtest is
# covered by its own line, then by its parent test's. The ceiling replaces the default limit for that entry.
#
# THE CEILINGS ARE A RATCHET. Each is about 1.5x what the entry took when it was added, measured with -p 4 on a
# busy Windows box, so a runner is under it with room. When you make something faster, lower its line. Do not
# raise one without saying why in the reason. A line that is no longer needed should be deleted.
