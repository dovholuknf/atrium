# f-012: provision-room.ps1 -Remove and -Restart finish what f-007 found

Found while proving f-007 on claudevm (2026-09-29). Two gaps in `scripts/provision-room.ps1`.

## 1. -Remove leaves room-git's clone behind

`room-git.ps1 init` (called by provision at the end, unless `-Repo none`) makes `~/git/...` on the remote and a
`~/.room-git` record. `-Remove` undoes everything else a run did, from the manifest, and leaves both. It also leaves
the git remote `<room>` that `init` added on THIS machine.

What is wanted: `-Remove` undoes room-git's part as well, by calling room-git.ps1 (a `remove` or `-Remove` verb there
if it has none) rather than knowing its layout. The clone may hold unpushed work, so it is removed only when it has
nothing that is not on this machine: any branch or stash not present here keeps the clone, with a `warn` line that
names what kept it and the command to remove it by hand. The local git remote goes only when the clone went.

## 2. Every stop uses port 7781

Every `atrium stop` in the script is `--url http://127.0.0.1:7781` (the -Remove, -Restart, binary swap and upgrade
paths, Windows and Unix). The manifest records the room's `ports`, and -Restart already reads them for its plan
(`$portsText`). A room whose ports differ is never stopped, and the script then waits on ports that never close.

What is wanted: one place that says which URL stops this room, from the manifest's ports, falling back to 7781 when a
manifest has none. Every stop uses it.

## Proof

Only on claudevm (autostart, stop, restart and -Remove tests are claudevm only). Provision, then -Remove, then check
that nothing of room-git's is left. Then provision with a non-default port, and check that -Restart -Yes stops and
starts it.

## Built

- `room-git.ps1 remove <room> [-Force]` reads the clone's branches, stashes and dirty trees. It keeps the clone, and
  the local remote, with a `warn` when a branch or stash is in no local branch or tag or anything is uncommitted.
  Otherwise it removes the clone, `<clone>-worktrees`, `~\.room-git` (Windows) and the git remote, only under the
  remote home. `-Remove` calls it unless `-Repo none`.
- `Get-StopUrl` in `provision-room.ps1` reads the first of the manifest's `ports` (else 7781). It is set as `$StopUrl`
  in every remote script's preamble, and all eight `atrium stop` calls use it. The -Restart plan prints it.
- Proved on claudevm: `room-git init` then `remove` leaves no clone, no `~\.room-git`, no remote. With an unpushed
  branch it is kept with the warn, and `-Force` removes it. A -Restart plan on m1mini is unchanged.
- Not proved: a full provision then -Remove, or `-Restart -Yes` on a non-default port. A provision joins this machine's
  hub, and the script has no option that sets ports (only a hand-edited manifest).
