# f-018: `atrium session` on Linux, with the native claude install

Found by f-016 on m1mini (2026-09-29). The native claude install is a file named for its version
(`~/.local/share/claude/versions/2.1.285`), so the kernel's process name is `2.1.285`, not `claude`. On macOS f-016
matched argv[0]'s basename as a fallback. Linux has the same install, and `ancestry_other.go` reads only the name
from `/proc/<pid>/stat`, so `runnerPID()` is very likely 0 there too (sg4-wsl, cdwsl, any Linux room).

What is wanted: check it on a Linux room first (sg4-wsl, testing only), and if it fails, add the same fallback to
`ancestry_other.go` from `/proc/<pid>/cmdline` (argv[0] up to the first NUL, basename, lowercased). Small, one worker.
