# f-014: room-check.ps1

Status: DONE, in claude/main (`add59d7d`).

Item 2 of `docs/fabric/room-requirements-design.md` section 7.

## What and why

A room is only known to be ready when a worker fails on it. `room-check.ps1` reads the project's requirements file
through the binary and checks the room against it before a launch, with the fix beside each failure.

## Built

- `scripts/room-check.ps1 <room> [-Project] [-File] [-Fix] [-Yes] [-Target] [-NoSmoke]`. It calls
  `room-toolchain -Check`, `room-git init -Check` and `push-base`, `room-gate -Check`, provision's `-SmokeOnly`, and
  the room's `/v1/harnesses`, `/v1/preflight` and `/v1/hooks/install` through the hub. It parses no YAML.
- `/v1/preflight` answers through the hub on sg3, so its toolchain rows are measured from the room. m1mini's room
  does not answer, so it says `warn measured from ssh, not from the room`.
- Not built, `skip`: state dir, runner sign-in, `survives`, env, services, codex smoke.
- The call to add to provision-room.ps1, once f-015 is merged: last step, after smoke,
  `pwsh -NoProfile -File room-check.ps1 $Name -Target $Target -NoSmoke` with the same `-Ssh` and `-SshOption`,
  a non-zero exit printed as `provision check warn`.
- Untested: `-Fix -Yes` (hooks, restart) and the `-Fix` runner-row edits, since no real room may take them here.
