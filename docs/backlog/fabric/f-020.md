# f-020: the hub audits every mutating control call, with its caller

Status: built (f-020 worker, branch claude/f-020). Owned by @fabric. From `docs/rnd/gateway-fit.md` section 4, idea 2,
filed by atrium-87300 2026-09-30.

## The problem

The control MCP (`internal/link/control_mcp.go`) records one audit kind from a tool call, `launch-refused`. A launch
that went through, an exit, a cull, a `restart_atrium` and an alias change leave no hub audit line naming who asked.
"Who culled that worker" and "who restarted sg3 at 03:10" cannot be answered from the hub.

## Design

1. **One wrapper, in `server()`.** `audited(c, kind, h)` wraps a typed tool handler and records one line after the
   call returns, success or failure. The list of audited tools is then readable in one place, the registration, and a
   new mutating tool is audited by wrapping it there.
2. **What is audited**: `atrium_launch` (kind `ctl-launch`), `atrium_exit` (`ctl-exit`), `atrium_cull` (`ctl-cull`),
   `restart_atrium` (`ctl-restart`), `atrium_wake_after_restart` (`ctl-wake`), and `atrium_alias` when it sets or
   clears (`ctl-alias`). The existing `launch-refused` stays as it is, so nothing reading it changes.
3. **What is NOT audited**: the read tools (`atrium_status`, `atrium_peers`, `atrium_task`, an alias read), and
   `atrium_say` and `atrium_report`. Say and report are the busiest calls by far, the room already keeps its own say
   log per card, and the hub's audit table keeps 5000 rows (`hubstore/audit.go` `auditCap`). A say per line would
   push the attach, detach and restart history this log exists for out within days. A say that WAKES a parked session
   is the exception worth a line (`ctl-wake-say`), because it costs a cold start.
4. **The line.** Room is the TARGET room (where the card is, or the room restarted). Detail is
   `by <agent>@<caller room> (claimed): <what>, <ok | the error's first line>`, for example
   `by f-006@claude-sg4 (claimed): cull 01a0f006 into claude/fabric, ok`. "(claimed)" is on every line because
   `X-Atrium-Agent` is a header anybody on loopback can set. The line records a claim, never a proof.
5. **Never the payload.** No prompt, brief, message text or env values in the detail, only ids, handles, room names,
   branch names and the outcome. The audit log is shown on the board, and a brief can hold anything.
6. **Best effort**, as `c.audit` already is: a failed write never fails the tool call.

## Tests

Each audited tool writes exactly one line, with the target room, the caller and the outcome. A failed call writes
its error. A read tool, a say and a report write nothing. A say with `wake` writes `ctl-wake-say`. No line contains
the prompt, brief or message given.

## Reviewed by @rnd (2026-09-30): accepted

- Say and report stay out, except a say with `wake`. No separate cap for `ctl-*`: 5000 mutating rows is weeks.
  Revisit only if attach and restart history is actually pushed out.
- **Refusals are recorded too**, not only ok or error from a handler that ran. A refused launch (the cap, a bad cwd)
  is the line somebody looks for. `launch-refused` folds into the wrapper, so there is one path.
- A cross-room call writes its line on the TARGET room only, with the caller's room in the text. No second copy on
  the caller's room.

## Built (f-020 worker)

- `internal/link/ctlaudit.go`: `audited(c, kind, describe, handler)` wraps a typed handler and writes one `c.audit` line
  after it returns. `server()` applies it to `atrium_launch`, `atrium_exit`, `atrium_cull`, `restart_atrium`,
  `atrium_wake_after_restart`, `atrium_alias` (a set or clear only) and `atrium_say` (only with `wake`).
- Each tool has a small `describe*` function giving the target room and the "what". None reads a text field.
- Refusals: a launch turned away by the cap or a missing cwd returns a `refusedError`, which the line writes as
  `refused: <why>`. The kind is `ctl-launch`. The old `launch-refused` kind is no longer written.
  `internal/api/web/js/audit.js` still lists it in `AUDIT_KINDS` (the filter dropdown only), so the board wants
  `ctl-*` kinds added there. That file was not touched.
- Tests: `internal/link/ctlaudit_test.go`.
