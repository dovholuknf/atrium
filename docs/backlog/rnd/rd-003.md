# rd-003. Decision 18: what proves a room's name over an overlay, OpenZiti versus zrok (design)

Status: research by @rnd, 2026-09-30. Raised by clint through atrium-87300. Research only, no code.

Decision 18 in `docs/decisions.md` is an open question: over direct mTLS a room's name is bound by a secret spent
once and a certificate the hub signs, but a ziti or zrok join string is unsigned JSON, so anybody the overlay lets
through can attach as any room. The answer decides what binds a room to an overlay identity, and whether OpenZiti
and zrok get the same answer. The result is `docs/rnd/overlay-room-identity.md`, with a recommendation.
