# r-026. atrium_cull's `tip` refuses an abbreviated sha (bug)

Status: BUILT

`inspectCullProved` compared the branch head, a full sha, with the tip as typed, so a short tip read as "new commits".
The tip is now resolved to a full commit in the worktree's repository (`resolveTip`, `internal/daemon/cull.go`).
A tip that is not a commit there and an ambiguous short sha are each refused with their own message, and the
"new commits" error shows both shas at one length. Merged-worker auto-cull and the cross-room proof (`MergeProof`)
already use full shas and needed no change.
