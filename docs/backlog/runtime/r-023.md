# r-023. `atrium hook --event permission`, atrium's own permission gate

## What

A Go subcommand that replaces the dotfiles script `atrium-perm-hook.ps1`. It reads Claude Code's PreToolUse JSON on
stdin, probes `GET /gate` (3s, `ATRIUM_PERM_PROBE_TIMEOUT`), skips read-only tools, POSTs `/permission` with no
deadline (`ATRIUM_PERM_TIMEOUT` sets one) and prints `hookSpecificOutput` with allow or deny, plus `updatedInput`
when the human edited the command.

## Why

The gate was a pwsh script every machine had to carry in its dotfiles. The binary is already in every room, and
atrium can then register it in settings itself.

## Where

`internal/cli/hook_permission.go`, dispatched from `internal/cli/hook.go`, tests in
`internal/cli/hook_permission_test.go`. The wire contract is the header of `internal/daemon/permwait.go`, unchanged.

## Notes

The dedup key and `tool_use_id` are both the payload's `tool_use_id`, with a session, agent, tool and summary hash
only when it is absent. Every failure exits 0 with no output. The skip list is checked before the probe, which is
equivalent and saves a request.

## Status

Built and tested. Registering it in settings (`WantedHooks`) is @fabric's.
