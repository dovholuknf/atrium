# r-012. Usage buckets count replies, so the usage tab's cause rows stop saying "0 calls" (bug)

`UsageSums` in `internal/store/usagebuckets.go` has no replies count, so every cause row on the usage tab reads
"0 calls". A `session_usage` row already stores its `replies`.

- `UsageSums` gains `Replies int64` with json `replies`. The bucket SQL sums `replies`, and `add` adds it, so a
  bucket's totals, per card and per cause all carry it.
- The live `usage` SSE event row carries `replies` too, so rows that arrive between reads count as well.
- Test: a bucket's `replies`, per total, card and cause, equals the sum of the rows it was made from. The event
  carries the row's `replies`.
