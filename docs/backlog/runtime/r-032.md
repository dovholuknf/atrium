# r-032. The keep-alive view says when a card was last refreshed and when it will be next (feature)

Status: not started. Owned by @runtime. Asked by @ui 2026-09-30 for u-032 (cache state on every card, clint's top
item). Room-side.

- `keepaliveCardView` gains `last_refresh_at`, the time of the last refresh in the current idle stretch, omitted when
  there was none.
- It gains `next_refresh_at` ONLY when `decide()` would actually refresh, which today means the card's why is "not
  due" (per @rnd). Omitted for every other skip reason (off, stopped, cold, under 50k, not idle).
- `/v1/settings` gains `cache_keepalive_today_refreshes` and `cache_keepalive_today_tokens`, counted tokens spent by
  keep-alive since local midnight, beside the existing week figure.
- Until these exist the board infers next as warm_until minus keepaliveMargin, and it prefers these once present.
