# r-049. cr2 daemon and roomstats lows

Status: open. Owned by @runtime. Found by @review's cr2 correctness review: four LOWs
(`docs/review/cr2-ada747b-2ce6443.md`). Still present at claude/landing 9429ac65.

1. **A blank kit name tags the card lean, but the launch is not lean** (daemon/launch.go:998-1005 on landing). Proven.
   - The cause: the refusal check and `leanOptions` count names after `cleanKitNames`, which drops blank names. The
     retag block tests the raw `len(req.LeanAgents) > 0`.
   - The result: `{"lean_agents":[" "]}` with no `lean` key launches a full session tagged `atrium:lean`. Its next
     restart, resume or keep-alive fork then starts lean.
   - Fix: compute `cleanKitNames` once in launchLocked and test those lengths.
   - Test: POST /v1/launch with `lean_agents:[" "]` gives a card without `atrium:lean`.
2. **`resolveTip` takes a ref named like the short sha, and git's warning joins the sha** (daemon/cull.go:311).
   Proven. It fails closed, but with a garbled refusal.
   - Fix: read stdout only, with `--end-of-options`. Or require a full 40-hex sha, or resolve with
     `--disambiguate`.
   - Test: build a repo with commits a and b, plus a branch named after a's 7-char sha that points at b.
     `resolveTip(dir, a[:7])` must return a.
3. **Lean plugin directories are never pruned** (daemon/lean_agents.go:169). Found by reading.
   - Every edit to an agent or skill file writes a new hash directory, and a crash leaves `tmp-*` behind.
   - Fix: when the daemon starts, remove `tmp-*` directories older than an hour, and any hash directories that no
     live card's kit names.
4. **A skipped CPU reading leaves the old `cpu_pct` showing as current** (roomstats/roomstats.go:339-348).
   Unproven.
   - Fix: when `cpuBusyPct` skips a reading, clear `CPUPct` or set `StaleSince`.
