# r-045. The settings importer applies deny-first for every tool, as Claude Code does (feature)

Status: not started. Owned by @runtime. Split out of r-034 by @rnd's review (Q1), 2026-09-30.

r-034 drops an MCP allow that a deny or an ask covers at import, which restores Claude Code's deny-first order for MCP
tools. @rnd agreed the same is right in principle for Bash, Edit and the rest, since an import should mean what the
file meant, but not in r-034: it changes what an existing import produces and deserves its own test list.

- The importer (`internal/claudeconf/claudeconf.go` `convert`) drops, and reports, any allow that a deny or an ask in
  the same file covers, for every tool atrium gates.
- A re-import of a file already imported says which of the rules it made before would now not be made. It never
  deletes an existing rule silently.
