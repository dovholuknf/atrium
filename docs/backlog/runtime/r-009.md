## r-009. A "task" event carries the same row as a list row

Status: built on branch claude/r-009. Owned by @runtime.

What: `Server.PublishTask` in `internal/api/api.go` builds the `/v1/tasks` row for one card (asks_open, replies_owed,
seen, the daemon hook fields, and `row: 1`) with per-card queries `OpenAskCount` and `RepliesOwedFor`. Every "task"
broadcast, including the daemon's `publishTask`, goes through it.

Why: the board re-pulled about 564 KB of `/v1/tasks` every 2 to 3 seconds because an event could not stand in for a row.
