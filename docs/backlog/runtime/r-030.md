# r-030. The new-context capture guard

Status: BUILT 2026-09-29 on `claude/r-030` by @runtime. Found when @ui's cycle failed on a handoff written a minute
before capture began.

The capture prompt now carries a per-run token line, `atrium-capture: <generation>-<random>`. `handoffWritten` accepts
the file when that exact line is in its first 4 KB, or when its mtime is at least the capture start minus 2s. A file
under 200 bytes is refused either way. Each refusal (missing, token absent and older, too small) is one sentence naming
the file, the directory and what the card should have done. Every path goes through `ncCapture`, so the manual button
and idle parking both get it.

Rejected by @rnd: accepting any write inside the last completed turn, and adding turn timing to activity.
