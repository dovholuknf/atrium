# r-028. A launch whose title gives an existing wire name silently re-prompted the old card (bug)

Status: BUILT 2026-09-29 on `claude/r-028` by @runtime worker. Found by @fabric in f-015.

`launchedName` only avoided names worn by a LIVE runner, but `Register` matches a wire name at any status, so a
title matching a done or dead card returned that card. Chosen fix (a): `wireNameTaken` counts every card, so the
name gets the usual `-2` suffix and a new card starts. Explicit TaskID, `IfRunning`, resume and adoption never reach
`launchedName`, so they are unchanged.

Code: `internal/daemon/launch.go`. Test: `TestLaunchedNameSkipsADeadCardsName` in `unique_name_test.go`.
