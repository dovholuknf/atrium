# r-044. launchedName can spin forever when the store halts (bug)

Status: BUILT. Found by @review while checking r-028. Owned by @runtime.

`store.WireNameHeld` answered true on any error, so `launchedName` looped without bound once the store halted
between the launch's harness read and its naming, holding the launch path.

`WireNameHeld` now returns `(bool, error)` with `sql.ErrNoRows` as not held. `launchedName` fails the launch on a
store error before any card exists, and stops at 1000 suffixes with an error naming the base. Tests in
`internal/daemon/unique_name_test.go`.
