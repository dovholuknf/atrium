# r-029. Automatic new context at a context size threshold

Status: BUILT 2026-09-30 on `claude/r-029b` by @runtime workers. Design: `docs/archive/auto-new-context-design.md`.

Settings `auto_new_context` (off, tagged, agents; default off), `auto_new_context_k` (default 300, never below `context_threshold_k`) and `auto_new_context_idle_s` (default 45). A subject card idle past the line gets the manual new context sequence with the chip marked auto, one retry, a wake-only retry after a clear, and notices to the launcher of an agent card.

Code: `internal/daemon/autocontext.go`, with hooks in `contextsize.go` and `newcontext.go`; settings in `internal/store/autocontext.go` and `internal/api/contextsize.go`. Tests: `autocontext_*_test.go` in `internal/daemon`, `autocontext_settings_test.go` in `internal/api`, `autocontext_test.go` in `internal/store`.
