# r-024. A card's last replies as text, for the phone conversation page (feature)

Status: BUILT 2026-09-29 on `claude/r-024` by @runtime. M2 of @ui's mobile design (`docs/backlog/ui/mobile-design.md`,
Path 2, picked by clint), specified by @ui. Room-side: live at the next room restart.

`GET /v1/tasks/{id}/replies?n=` (n defaults to 3, at most 10), on the human listener only, answers
`{"source":"transcript"|"screen","replies":[{"at":"RFC3339","text":"...","truncated":false}]}`, oldest first.

- It reads the conversation the runner LAST STARTED (`d.ctx.sessionOf`), not the stored resume id, which after a
  /clear still names the old one (r-021 part 1).
- Main-chain assistant text only: no tool calls, no thinking, no `isSidechain` replies. One reply per message id, its
  text blocks joined.
- Bounded: the transcript is read from its last 2 MB, as the keep-alive's read is, and each reply is cut at 16 KB with
  `truncated: true`. The parsed tail is cached on the file's size and modification time.
- A codex card, or a card with no readable transcript, answers with its screen's rows as one reply, `source: "screen"`
  (the tail kept when it is over 16 KB). An unknown card is 404.

Code: `internal/daemon/replies.go`, `internal/api/replies.go`. Tests: `internal/daemon/replies_test.go`.
