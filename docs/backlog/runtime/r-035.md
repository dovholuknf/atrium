# r-035. Worker gateway, the atrium side (feature)

Status: BUILT on claude/r-035b. Owned by @runtime. Design in `docs/runtime/worker-gateway-design.md`.

A daemon setting `lean_worker_gateway` names an mcp.json server that stands in under the key `mercurius` for a default
lean launch. Naming `mercurius` explicitly or the tag `atrium:mcp:mercurius` gets the wide server. Cards carry a
`mercurius` field saying which. Not exported, no migration. The caller check on `:8088` is mcp-gateway's.
