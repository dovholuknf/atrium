## What the code says about 1

The totals already follow the toggle. `ucCards` (js/usage-charts.js) sorts and totals by `ucShown`, and each
card's per-bucket series is built with `ucShown` too (line 229, and js/usage-groups.js:70 for groups). In the "now"
shot the tiles add up to about 41.5M, which is the counted total in tokens by kind (32k + 8.7M + 1.9M + 31M), not
the 2061M of cache reads.

What misleads is the colour. The sparkline bars are `uck-cost`, `rgba(var(--teal-rgb), .8)`, which is the cache
read swatch (`uck-read`, the same teal) at a tint. So with cache reads hidden, the by-card tiles are drawn in the
one colour the legend says is not in the charts.
