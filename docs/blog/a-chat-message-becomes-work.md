# A chat message becomes work: the OpenWiki factory test

Series: Intake and PR review. Status: idea. Audience: people building agent intake.

**Hook.** A colleague's chat message turned into a spike, a build and a factory test, and showed thirty-one gaps.

**Angle.** The best test of a factory is a real outside request run end to end.

**Rests on:** inbox, sources, intake design, OpenWiki spike. See `docs/blog/inventory.md`.

## Story beats

1. A chat message pasted in by hand.
2. Four questions answered in one line each.
3. Patches moved between rooms by hand because they were too big for messages.
4. The gaps: the gate ran after the build, a fake could not see the real resource, a test spent real shares.
5. What intake would have done.
