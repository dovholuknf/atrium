# The pause: an AI company that can only write plans

Series: The software company: directors and workers. Status: idea. Audience: engineering leads.

**Hook.** The human stopped every build and deploy; the org kept going, and produced eight designs in a day, all reviewed.

**Angle.** Stopping a factory needs a scope and named exceptions, or the pause lives only in someone's notes.

**Rests on:** the pause, named exceptions, freeze and budget design. See `docs/blog/inventory.md`.

## Story beats

1. Why the pause: too much in flight to keep track of.
2. Named exceptions, recorded nowhere but a handoff.
3. What an org does when it can only design: hub forge, change record, lifecycle, runner switch, review on atrium.
4. Each design held for review, with questions held until asked.
5. The freeze and budget design: a pause that atrium itself enforces.
