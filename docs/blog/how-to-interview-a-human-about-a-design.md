# How to interview a human about a design

Series: The one human. Status: idea. Audience: anyone who asks people questions for a living.

**Hook.** Scenario first with real machine names, 'this happens, then this, then what?', one default each, and never re-ask.

**Angle.** Questions in sequence form get answers; questions about mechanisms get confusion.

**Rests on:** interviewer brief, interview mode. See `docs/blog/inventory.md`.

## Story beats

1. The first try: questions back to front, not understood.
2. What worked: one question at a time, a default each, an answers file as he went.
3. The rules: picture first, then mechanisms, then edge cases.
4. Never re-ask; take what he said in passing as given.
5. The interview screen: one question, buttons, back.
