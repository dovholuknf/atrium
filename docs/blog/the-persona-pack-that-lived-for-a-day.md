# The persona pack that lived for a day

Series: The software company: directors and workers. Status: idea. Audience: people building agent personas.

**Hook.** Six stages of specialist agents with memory were built and reverted the same day; personas came back two weeks later as standing reviewers.

**Angle.** Building far more than asked is its own failure, even when the idea comes back.

**Rests on:** persona pack (reverted), standing reviewers design. See `docs/blog/inventory.md`.

## Story beats

1. What was asked for: a few files.
2. What was built: a catalog, review-with, a lessons view, a pack nag.
3. Reverted the same day.
4. The return: standing reviewer personas with a knowledge base on the hub.
5. The difference: one job, one knowledge base, review before a lesson counts.
