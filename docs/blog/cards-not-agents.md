# Cards, not agents

Series: Cards, not agents. Status: idea. Audience: people designing agent UIs.

**Hook.** The unit on atrium's board is a card: a piece of work with a live session, a history, an owner and a state, not an agent persona.

**Angle.** Treating sessions as tasks with state is what makes 'which one needs me' answerable.

**Rests on:** attention columns, seen tracking, archive, inbox, card URLs, handles. See `docs/blog/inventory.md`.

## Story beats

1. Attention columns: needs permission, ready, running, finished, shelved.
2. Question versus finished turn, from the Notification hook.
3. Seen tracking and open questions; archive instead of delete.
4. Readable card URLs made of names, and handles agents use to talk to each other.
5. Where the persona idea went (see the persona pack post).
