# What the review HOLDs caught

Series: The software company: directors and workers. Status: idea. Audience: people adding review agents.

**Hook.** A reviewer agent that holds about one change in five, mostly with a proof: forgeable facts, a stale picture, the human quoted in a public repo.

**Angle.** Review that stands outside the department finds what the department cannot.

**Rests on:** Atrium-Verdict trailers, deploy-ready, the review director. See `docs/blog/inventory.md`.

## Story beats

1. The numbers: dozens of HOLDs, each a commit with a verdict trailer.
2. Kinds of catch: races, claims of test runs that could not happen, evidence a session could forge.
3. Design holds: a wall keyed on a branch name the agent chooses; signing that works only the first time.
4. Public-repo holds: the operator quoted verbatim.
5. Why the reviewer runs on the strongest model.
