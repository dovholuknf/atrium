# A PR review that never posts

Series: Intake and PR review. Status: idea. Audience: people using agents for code review.

**Hook.** From an hour and fifty minutes and $7 to a target of ten minutes and $2, by forking one primed session for every reviewer.

**Angle.** Prime once, fork reviewers, merge findings in code, and leave posting to the human.

**Rests on:** pulls tab, PR review runner, walk drawer. See `docs/blog/inventory.md`.

## Story beats

1. The first review by hand, and the walk format the human liked.
2. One checkout, one primed session, reviewer, verifier and critic forks.
3. Findings as files and a walk on the board.
4. Never posting to GitHub.
5. What is still not measured end to end.
