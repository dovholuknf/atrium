# Removing the middle manager

Series: The software company: directors and workers. Status: idea. Audience: people building agent orgs.

**Hook.** The orchestrator rewrote dozens of reports a day for the human; the plan moves that relay into plain code on the hub.

**Angle.** A model in the middle of every message is the most expensive pipe you can build.

**Rests on:** factory refactor, clint inbox, decision list. See `docs/blog/inventory.md`.

## Story beats

1. What the orchestrator did by hand: relays, moving patches between rooms, landing, culling.
2. About forty relays in one window, each rewritten.
3. The inbox: questions and answers as data on the hub, parsed with no model.
4. Five steps to take the orchestrator out.
5. What stays a model's job.
