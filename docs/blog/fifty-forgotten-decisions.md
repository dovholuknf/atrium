# Fifty forgotten decisions

Series: The one human. Status: idea. Audience: people working with many agents at once.

**Hook.** Counting the decisions an operator of an AI org skipped, and why the fix is a numbered list parsed by plain code, not a smarter model.

**Angle.** Losing track is a data problem: one list, numbered, never reused, answered by number.

**Rests on:** decision list, typed effect, safe defaults, one reminder a day. See `docs/blog/inventory.md`.

## Story beats

1. Answering the newest question and skipping older ones.
2. Fifty counted.
3. One list on the hub, answered as '12 y, 14 n'.
4. Defaults only for internal, undoable effects.
5. One reminder a day instead of a nag ladder.
