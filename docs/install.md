# Install atrium

macOS and Linux:

```sh
curl -fsSL https://raw.githubusercontent.com/dovholuknf/atrium/main/install.sh | sh
```

Windows, in PowerShell:

```powershell
irm https://raw.githubusercontent.com/dovholuknf/atrium/main/install.ps1 | iex
```

The rest of the first run, building from source as the fallback, and what to do after it works are on one page:
[`website/docs/get-started.md`](../website/docs/get-started.md). The install script's options are in
[`website/docs/install.md`](../website/docs/install.md#install-script-options).
