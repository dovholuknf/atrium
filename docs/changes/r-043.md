# r-043. Launch-onto test flaked waiting a fixed 5 s for the daemon

`safeBuf.waitFor` (daemon_test.go) polled the log for "ready. ctrl-c to stop" for 5 s. Under load runner resolution
alone took 4 s, so TestStartedOntoLeavesACardAHookAlreadyMoved failed. It now blocks until a write to the log makes the
line appear, with no timeout of its own. Every caller (startDaemon, startDaemonWith, fresh_test.go) gets the fix; no
other fixed log-line wait exists in the package. Assertions are unchanged.
