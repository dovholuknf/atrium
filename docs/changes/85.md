# 85. The headless board run flakes under load

## Changelog

- Every Playwright timeout in `scripts/test-board-headless.js` goes through `slow()`, which multiplies it by
  `HEADLESS_SLOW` (1 when unset). A loaded machine can be given more time without editing the script. Sleeps are not
  scaled, because a sleep that proves something stays put has to keep its length.
- The terminated-terminal dismiss check says which of its three waits ran out and for how long, instead of throwing
  out of the run as "the headless run threw" with no name. Its menu wait opens the menu again if a render closed it,
  rather than waiting out the whole budget on a menu that is no longer open.

## Test plan

1. Run the full headless run on an idle machine. It passes as before.
2. Run it with `HEADLESS_SLOW=3` while `go test ./...` runs beside it. It passes, and takes no longer on the checks
   that pass.
3. Break the dismiss entry in the card menu locally and run it. The failure names the menu wait and its budget.
