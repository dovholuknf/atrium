## Test plan

## @LETTER@. Test what was touched, and the whole suite after landing

### @LETTER@1. The mapping

1. `node scripts/test-touched-selftest.js`

**Expected:** `test-touched-selftest ok` in under a second. It checks the packages, the integration tag, the units,
the node scripts and the warnings chosen for fake changed-file lists.

### @LETTER@2. A plan for a diff

1. Change a Go file, a board file such as `internal/api/web/js/toasts.js`, and a script, without committing.
2. `bash scripts/test-touched.sh --base HEAD --plan`

**Expected:** one line per item with the reason it was picked: the Go package, bootClean and the toast units, the
node scripts that read the file, a syntax check of each changed script. A changed board file that maps to no unit
(an image, say) gets bootClean only and a WARNING line.

### @LETTER@3. The run

1. `bash scripts/test-touched.sh --base HEAD` with the changes above.

**Expected:** each step prints ok or FAILED with its time, the total is under two minutes, and the exit is non-zero
when any step failed. Without playwright the headless step says SKIPPED rather than passing quietly.

### @LETTER@4. The whole suite refuses without FULL_SUITE

1. `bash scripts/check-board.sh`, `node scripts/test-board-headless.js`, `node scripts/test-board-sharded.js --local`

**Expected:** each exits 2 and names `scripts/test-touched.sh`. With `HEADLESS_UNITS=bootClean`, `--units bootClean`
or `FULL_SUITE=1` each runs. `bash scripts/ci.sh --only board` runs the full suite, since it sets `FULL_SUITE=1`.
