## Test plan

## @LETTER@. The worker gateway

### @LETTER@1. Empty setting changes nothing

1. Leave `lean_worker_gateway` empty and launch a lean worker.
2. Open the card's details.

**Expected:** The worker's `mercurius` is the runner's normal entry and the card shows no `mercurius:` line.

### @LETTER@2. A default lean launch gets the narrow server

1. Add a `mercurius-worker` entry to the runner's mcp.json and set `lean_worker_gateway` to `mercurius-worker`.
2. Launch a lean worker with no `mcp` field.

**Expected:** The card shows `mercurius: mercurius-worker` and the worker's mercurius tools go through that server.

### @LETTER@3. Naming mercurius gets the wide server

1. Launch a lean worker with `mcp: ["mercurius"]`.
2. Restart it.

**Expected:** The card shows `mercurius: mercurius (wide)`, before and after the restart.

### @LETTER@4. An unknown name is refused

1. Set `lean_worker_gateway` to a name mcp.json does not have and launch a lean worker.

**Expected:** The launch is refused and the message lists the server names mcp.json has. A URL as the setting is refused
when saved.
