## Test plan

## @LETTER@. One clock for the headless suite

`scripts/test-board-headless.js` shifts time instead of freezing it. `Date.now()` and a no-argument `new Date()` answer real time plus a constant, in Node and in every browser context, so a run starts at 12:00 local whatever the real time is. `new Date(x)`, `Date.parse` and `Date.UTC` are untouched, as are `Date.prototype` and `instanceof Date`.

### @LETTER@1. The self-check
`HEADLESS_ONLY=clock node scripts/test-board-headless.js` passes: the page reads 12:xx, a window the page opens with `window.open` agrees, Node and the page are within 2 seconds, and time advances.

### @LETTER@2. Across midnight
`HEADLESS_CLOCK=23:58 HEADLESS_ONLY=clock,usageLimits,cacheChip,cacheLine,keepalive,usageCacheReads` passes, and so does the same run without the variable.

### @LETTER@3. Overrides and the opt-out
`HEADLESS_CLOCK=real` turns the shift off and `clock` still passes. A context made with `browser.newContext(opts, { realClock: true })` sees the real clock. No section uses it today.
