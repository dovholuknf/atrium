# u-017: phone terminal focus no longer bounces or hides the text

## Changelog

- Fixed: on a phone, tapping the terminal to type showed the top of the page and bounced up and down. xterm's
  hidden helper textarea was pinned to the grid's top-left, so the browser's focus scroll dragged the pane to the
  top and the cursor keep scrolled it back. The textarea now sits at the cursor on a phone (`terminal.css`, the
  desktop pin is unchanged), and is moved there synchronously on every write.
- The cursor keep only acts when the cursor, the pane box or the visual viewport changed, so it cannot answer its
  own scroll. A focus of the terminal forces one keep. The page is held at scroll 0 in the terminal view.
- The pop-out window (`solo.js`) and the desktop terminal are untouched.

## Test plan

Automated: `HEADLESS_ONLY=phoneFocus,phoneView node scripts/test-board-headless.js` (`phoneFocus`, portrait and
landscape, focus scroll simulated). Landscape does not shrink the height, because the landscape layout leaves the
terminal pane about 10px tall (u-016's header collapse).

Manual, on a real phone:
1. Open a terminal, tap it. The keyboard opens and the cursor row stays visible; the view does not jump to the top.
2. Type while output streams. The view follows the cursor down with no up-and-down bounce.
3. Tap elsewhere in the terminal, dismiss and reopen the keyboard. The page never shows the board header scrolled away.
4. Rotate; repeat. Open the same terminal in the pop-out window and on desktop: unchanged.

## u-017b: a manual pan wins

### Changelog

- Fixed: panning a phone terminal sideways was snapped back by the cursor follow. While a finger is down, and after
  the reader has panned by hand, output never moves the pane. The follow comes back only on input (typing, the key
  bar, a paste) or a tap on the small "follow" chip, which shows only while the follow is off.
- A focus scroll the browser does for the textarea is undone while a manual pan holds.

### Test plan

Automated: `HEADLESS_ONLY=phonePan,phoneFocus,phoneView,u016 node scripts/test-board-headless.js`.
Manual: on a phone pan sideways while output streams (the view stays where you put it and a "follow" chip appears),
type a key (the cursor comes back and the chip goes), pan again and tap "follow".
