# atrium v0.2.0

## Changes

- Move a room to another machine: it stops and undoes cleanly before the park, on the hub and on the board
- First run has a step to set the context limit; the lowest limit is 50k, shared with keep-alive
- Launch dialog: the folder box only browses a folder inside a browse root, and a refused browse answers with an empty listing
- Hub branches: stale and deleted branches no longer pile up in the repos view
- Phone: open questions answer in place, and the transcribing ring is back on the mic, composer and answer box
- Phone: usage and queue views
- Hub profile row keeps an unsaved edit when the profile is read again
- Hook-delivered human messages show as prompts in the phone thread
- Tests: the busy-upload test paces its writer like a real session and names the slow phase when it misses its bound
