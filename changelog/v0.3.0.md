# atrium v0.3.0

## Changes

Terminals list
- A launcher and its launched cards sort as one group, and nested cards sort by when they started
- Re-parent a card under a parent on another room by its name@room handle
- A pinned card keeps its repo colour and sorts by its changes age
- Terminal find no longer jumps to the bottom
- atrium.ziti links and file path links open from the terminal
- Copy and emoji keys work in the terminal

Launch
- A repository whose name starts with a dot can be launched
- A missing folder and an empty worktree on sg3 launch cleanly
- A pasted link wakes the existing card
- A PR card with no ready review walks its branch instead of an empty walk

Deploy and tools
- Tools reconnect after a deploy, and stale tool schemas are refreshed
- A deploy keeps a card's atrium control and the sgg runners running

Hub
- Idle git polling is quiet
- Collecting from sg3 no longer answers 404
- Each room reports its hardware, and a launch can ask for a GPU or VRAM
- Peers show what a needs-input card waits on
- A card's file links work on the room's own port

Board
- Experimental feature flags, with the unfinished tabs split out
- An attention queue
- Card files that are .md render as pages
- Finished cards close
- The mic beep no longer comes late, and dictation has settings

Runners
- opencode runs on local models, with local AI probes
- Push to talk works on every runner
- opencode permission asks go through atrium's own chain
