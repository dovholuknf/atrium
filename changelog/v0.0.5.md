# atrium v0.0.5

## Highlights

- A walk reply is saved the moment it is sent, so closing the page quickly keeps it, and a walk link opened in a fresh
  page opens the walk after the restore rewrites the hash.
- Closing a card removes its home folder when the folder holds no file.
- Window mode on a machine without wt.exe gives the runner its own console instead of NUL, so a room without a
  desktop no longer kills it.
- The rooms popup flags a room that runs a different commit than the hub.
- Age order shows the not-allowed cursor and badge only during a real drag, not on hover.

## Also

- **Walk:** a sent reply is saved at once, and a walk link in a fresh page survives the hash rewrite.
- **Close:** the card's empty home folder is removed.
- **Rooms:** the popup marks a room on a different commit than the hub.
- **Board:** the not-allowed cursor and badge in age order show only while dragging.
- **New context:** the wake message stays one sentence, and the says already sent go in the handoff.
- **Tests and CI:** test-touched runs the scripts/live tests that load a changed scripts/live file, defaults its base to
  hub/claude/main when the local claude/main lags it, and the live tests run on a room without sg4's D: drive with the
  409 test faking the room service. The rooms setup test allows the commit line before hooks.
