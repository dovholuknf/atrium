New context (manual button and idle parking) now asks the card to put `atrium-capture: <token>` in its handoff file, and accepts a file already written before the capture if it carries that line in its first 4 KB, so a card that answered "already written" no longer fails the cycle (r-030).
The old rule stays: a file written during the capture turn passes. A handoff under 200 bytes is refused either way, and each refusal names the file, the directory and what the card should have done.
