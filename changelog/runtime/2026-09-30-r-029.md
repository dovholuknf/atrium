Atrium can now start a new context by itself when a card's context passes `auto_new_context_k` (default 300k, never below the launcher notice). It is off by default, `auto_new_context` takes `off`, `tagged` or `agents`, and it waits for the card to be idle at its prompt (r-029).
It is the same capture, clear and wake as the New context button, with the chip marked auto, one retry on a failure, and a notice to the launcher of an agent card before it types and after it gives up.
