- **A worker's token use is now recorded when its work ends any way, not only at a Stop hook.** (Room deploy.) Usage rows were written only by the Stop hook handler, and workers launched by `atrium_launch` have no Stop hook (or end without one), so their spend never reached the ledger ($223 on m1mini). The same record path now also runs, after the transcript settles, on a report (`atrium_report`, `atrium finish`), a session end or leave, a terminate (`atrium_exit` / kill), and the runner's process exiting. It is the same read as a Stop's, main transcript and subagent files, so the transcript cursor and the reply times keep a second record over the same turns at zero: report then Stop, Stop then report, and an exit after both each count a reply once. The flush leaves the turn open (its cause and resume flag stay for the Stop that closes it). A failure to record is logged and never fails a report or an exit; a card with no resume id, no worktree, a non-Claude runner, or a transcript that is gone gets no row and no error. Old gaps are not filled by this: see `atrium usage backfill`. Item r-usage-no-stop.
