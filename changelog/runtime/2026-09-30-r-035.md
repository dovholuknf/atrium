- **Lean workers can reach mercurius through a narrower gateway.** Set `lean_worker_gateway` to a server name from the runner's mcp.json and a default lean launch gets that server under the key `mercurius`. Naming `mercurius` explicitly, or the tag `atrium:mcp:mercurius`, gets the wide one, and the card's details say which. Empty changes nothing. (r-035)
