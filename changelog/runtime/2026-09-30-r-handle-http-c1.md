- **`atrium task`, `atrium exit`, `atrium new-context` and `atrium launch --onto`.** Each names a card by its handle,
  alias, `name@room` or id, talks to the board's port, and prints what it reached. `atrium task --json` prints the card
  as the API answers it. `launch --onto` runs in the card's own directory unless `--cwd` says otherwise. Nobody
  hand-writes curl to cycle a director any more. (r-new-handle-addressed-http C1)
