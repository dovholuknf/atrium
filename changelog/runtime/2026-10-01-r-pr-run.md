- **The pulls runner.** `internal/daemon/prrunner.go` replaces the `runner not built` stub. A review fetches the PR
  into its run folder with `gh pr view`, `gh pr diff` and a blobless shallow `git fetch` of `pull/<n>/head` (each
  named, time-bound and read-bound like a source), builds `bundle.md` in Go, primes one `claude -p` with it (session
  kept), and runs every reviewer, verifier and critic as a one-shot fork of that session through `runForkProcess`:
  read-only tools, the lean flags, the permission gate off, so no fork waits on a permission. The forks of a step run
  at once. A merge fork dedupes and ranks, `render.Render` writes the finding files and `walk.txt`, and a Resend is
  answered once by asking the merge fork again with the rule quoted. `budget_usd` is checked between steps and `retry`
  raises it once. `run.log` and `review.json` record each step's cost and the forks' cache reads against the prime's
  write. A review is a row and never makes a card. Steps 6 and 7 (second opinion, settling) are P3. `forkSpec` gained
  `Stdin` and `Timeout`, and `forkReceipt` the answer text and model usage. Item r-pr-run.
