- **Standing rules can name MCP tools.** A rule for `mcp__server__tool`, a glob like `mcp__server__get_*`, or a whole
  server matches the tool and takes any input. The settings importer now reads MCP allow and deny entries (an allow
  that a deny or ask covers is dropped and reported, as Claude Code applies deny first), and approve-forever on an MCP
  call writes a tool rule. The rules API marks an old input-shaped MCP rule with `note`. (r-034)
- **A tie between two matching rules now goes to block, for every rule.** Before, two rules of equal specificity
  were settled by row order. An approve and a block of equal reach now always block. (r-034)
