- **A merged worker is culled without anybody remembering to.** A git `post-merge` hook runs `atrium merged`, the room
  marks the finished workers the merge covered, tells their launcher once, and culls them after `merged_cull_grace`
  (30 minutes, `off` disables it). A new turn or `atrium_cull hold=true` cancels it, and the work is recorded as
  accepted. (r-019)
- **`atrium archive-workers [--dry-run]`** archives the done worker cards already piled up on the board, never a
  director and never a card an agent did not launch. (r-019)
- **`atrium_launch` from an agent tags the worker `atrium:subagent`** unless it asks for `atrium:director`. (r-019)
