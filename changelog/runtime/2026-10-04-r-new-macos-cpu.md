- **A Mac room now reports machine CPU, so `GET /v1/room/stats` carries `cpu_pct` and `cpu_series_pct` on macOS too.** (Needs a rebuild and deploy to show on m1mini.) There is no cgo-free route to `host_statistics` and macOS has no `kern.cp_time`, so one long-lived `top -l 0 -s 5` streams a sample every five seconds and the stats read turns each into counters. No process is started per sample. CPU is absent until top's second sample, and stays absent if `top` is missing, as before. Item r-new-macos-cpu.
