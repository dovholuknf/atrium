- **A lean launch can keep named agents and skills.** `atrium_launch` takes `lean_agents: ["codebase-steward", ...]` and
  `lean_skills: ["review-panel", ...]`. The worker keeps the Agent (or Skill) tool and only those files from `~/.claude`,
  loaded through a session-only plugin in atrium's state, and nothing else of the operator's setup. They are started as
  `atrium:<name>`, because Claude Code namespaces plugin agents and skills. An unknown or unsafe name refuses the launch,
  codex and `lean: false` refuse the fields, and the card keeps the lists across a restart. (r-005)
