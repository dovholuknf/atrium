- **A pull request review now reaches its forge through a small interface in `internal/forge`, and GitHub is the first implementation, through `gh`.** (Repo only, no deploy.) The PR runner no longer names `gh`. The forge is picked from the PR's host: an enabled provider with that host and its new `forge` field, else the built-in default (`github.com` is github, `bitbucket.org` is bitbucket, which is not built). Any other host fails the row with `no_forge` and a sentence naming the host and how to set a provider. A provider gains `forge` and `forge_cmd`, the command NAME and never a token, saved through the provider API and validated in the store. A missing or logged-out `gh` fails the row with a sentence saying what to run. Item r-new-forge-interface.
