- **Bitbucket Cloud pull requests can be read through `bb`.** (Repo only, no deploy.) `forge.New("bitbucket", ...)` now builds a forge instead of answering `no_forge`. It runs `bb api` against the REST API 2.0 for the pull request, its diffstat and its diff, so the CLI owns the login and atrium holds no token. A fork PR is told by the source repository differing from the destination. The fetch is the source branch, from the fork's https URL for a fork PR, since Bitbucket has no `pull/N/head` ref. A missing or logged-out `bb` answers an access sentence naming `bb auth login`. Item r-forge-bb.
