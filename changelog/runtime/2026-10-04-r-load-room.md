- **`scripts/recognisers/load.ps1` now takes `-Room`, so the rows can be loaded through a hub.** (Repo only, no deploy.) Recognisers are stored per room, and a hub answers every PUT with a 409 until a room is picked. `-Room <name>` sends `X-Atrium-Room` and defaults to `$env:ATRIUM_ROOM`. A 409 now prints the hub's own sentence and the room list, and a 400 prints the compile error, instead of PowerShell's generic status text. The README lists `support.json` as well and notes that its rows default to the openziti/ziti worktree. Item r-load-room.
