- **`atrium twig <name>` turns a tangent found mid-work into its own branch.** Run it inside a worktree. The room
  makes a branch and worktree called `<name>` off that worktree's local HEAD, applies its tracked changes there
  unstaged as a binary patch, copies its untracked files, runs the setup hook and starts a card. A patch that does
  not apply is saved beside the new worktree and named. A name that is already a branch or a worktree is refused.
  `POST /v1/new` takes `twig`, the worktree to start from. (g-twig)
