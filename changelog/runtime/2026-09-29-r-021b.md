- **A conversation id no longer lands on the wrong card.** A session bound to its card by task id now takes its
  conversation back from a card with no live session, and is refused against a live one, with the reason written on
  both cards. A `claude` started inside an agent's shell can no longer change the parent's conversation, and a hook
  that only guessed its name from the directory never matches a finished card. (r-021)
