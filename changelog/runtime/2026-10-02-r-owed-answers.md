- **A worker that stops owing its launcher an answer leaves an open item on the launcher's card.** One for a worker that ended with no report, one whose last message to its launcher asked something (a `needs` say, or a report with an `ask`, the same test that keeps a done report from exiting the card), and one that has sat at needs-permission for 5 minutes (`ATRIUM_OWED_PERMISSION`). It is kept whether or not the launcher holds its notices, and the row carries `owed`, `owed_since` and `owed_no_launcher`. A done report with no ask, and an `fyi`, open nothing. The item closes when the launcher messages, exits, relaunches or dismisses the worker (`atrium_task` with `dismiss`) and by itself when its reason is gone, checked before every push. Reading the notices closes nothing. Item r-owed-answers, W6 of `docs/rnd/long-turn-checkin-design.md`.
- **At 10 minutes open, the orchestrator gets one held notice.** The card tagged `atrium:orchestrator` on the room, else the hub's through the relay outbox, else only the board's chip. Never the orchestrator about itself, and nothing is typed or written to the worker (`ATRIUM_OWED_PUSH`). After a `/clear`, a new context or a compaction, the launcher's first tool call carries one line listing its open items. A worker whose launcher no longer resolves keeps its item on the orchestrator's card, else on its own row. Item r-owed-answers.
- **A report that reaches nobody no longer reads as sent.** `reported_at` is stamped only when a notice was queued or held for the launcher, and an agent-launched worker that reports with no launcher is made visible to the orchestrator, held. The `launcherFor` fallback to `@human` is left as it was. Item r-new-report-no-launcher.
- **`atrium` is reserved.** No card may take it as a handle or an alias (`ErrReservedName`), including `atrium@x`, upper case, full-width, zero-width and Cyrillic look-alike spellings. A name a hook derives from a folder called `atrium` is kept as `atrium-dir`, and a launch with no title in such a folder, or titled "Atrium", is named `atrium-2`. atrium's own line to a launcher is sent as `atrium`. An existing card named `atrium` from before this change is passed over by a folder-derived session, which makes a new `atrium-dir` card; rename the old one by hand if you want to resume it. Item r-owed-answers.
- **Until the hub sends `tags` on `/peers`, a push to an orchestrator on another room reaches nobody.** The room finds it by the tag `atrium:orchestrator` only (an untagged card called `orchestrator` gets nothing), remembers the last one found for when the hub is away, and forgets it when the hub answers and lists none. With no tagged peer the board's chip is all there is. A note for @fabric: the hub's `/peers` should carry each card's tags. Item r-owed-answers, review M1.
- **A closed item stays closed.** An exit or a dismiss is not undone by the card going dead; an item reopens only for a new reason (a new question, a new permission wait, a new launcher prompt). An orphan's done report is its one notice to the orchestrator, and its push says it has no launcher. A card the operator launched still stamps `reported_at`; only an agent-launched worker nobody was queued to hear does not. Item r-owed-answers, review M2 to M4.
