# atrium v0.4.0

## Changes

Dictation
- A mic button in every text box on the board and the phone, behind the "mic in every input" experimental feature, off by default
- On the phone, releasing the hold-to-talk button in the message box sends the message when the mic switch is on

Runners
- A runner with no hooks takes its turns from what is on the screen
- A row with no opening prompt has its prompt typed in once the runner is ready
- Resume and restart keep a runner's own session id
- Every banner but the default runner's is typed without colour codes
- An aider banner is no longer read as a mouse report
- A turn that begins before the screen settled resumes, and an unanswered opening prompt is typed again
