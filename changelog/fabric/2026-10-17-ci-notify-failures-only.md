The hub hears of a failed CI run from the `ci` workflow itself. `ci-notify.yml` is gone. `ci.yml` has a last job `notify` that needs the others and runs only on `failure()`, so a passing ci, and every docs or release run, tells nobody. `scripts/ci-notify.sh` with no event file builds the body from the run's own push or pull request context, and still replays a recorded `workflow_run` event file, and runs by hand with no GitHub. The ziti-hook action sends it with the same secrets. The hub route filter stays as a second guard.
