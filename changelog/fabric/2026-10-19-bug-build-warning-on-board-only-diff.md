The rooms pill no longer warns "runs a different atrium build than the hub" when only the board differs. Each binary now carries a fingerprint of its Go sources, go.mod and go.sum (not the board, docs or tests), stamped at build and reported on `/v1/health` as `code` beside `build`. Equal fingerprints raise nothing. Different ones warn with both commits and which is newer. A room with no fingerprint keeps the board-hash compare. Item `bug-build-warning-on-board-only-diff`.
