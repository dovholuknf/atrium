- `scripts/room-toolchain.ps1 <target> -Profile c` provisions a Windows room to build openziti/ziti-sdk-c: MSYS2 mingw with gcc, cmake, ninja, openssl and pkgconf (an MSYS2 that is already there is used as it is), its `mingw64\bin` on the room's PATH record, git identity and Git Credential Manager access, vcpkg with the `x64-mingw-static` triplet, a ziti-sdk-c checkout, and a `CMakeUserPresets.json` with `cwdming` and `cwdming-with-tests`. Without `-Profile c` nothing changes.
- A step that needs a person (an admin's icacls, an interactive GitHub login, a git identity) is `needs-human`, the run ends with the exact commands, and the new exit code 6 means the run finished and a person is needed. `-Check` reports every C tool as a path and version or MISSING and writes nothing.
- On macOS and Linux the profile only reports the C tools. Item f-c-toolchain.
