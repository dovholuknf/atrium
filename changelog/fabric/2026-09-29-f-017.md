- The hub can run a command you write when a card needs you: a permission, a question, input, or a finished turn
  you have not seen. Set it with `PUT /_hub/notify` (off by default), test it with `POST /_hub/notify/test`. It gets
  the card name, reason, card and room as `ATRIUM_NOTIFY_*` and as one JSON line on stdin, never in argv. Nothing
  runs while a desktop board tab is visible, a room's first announcement is stored silently, and three failures in
  a row switch it off with the reason kept. (f-017)
