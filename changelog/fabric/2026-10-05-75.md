A new machine is now provisioned as `localai` and gets a shared folder for its clones. `provision-room.ps1` checks for the
account on a machine that is not yet a room, reusing the `-User` check, and when it is missing prints the platform's
create command and stops, since provisioning never creates an account or needs admin. A machine that already is a room,
such as sg3 on `claude`, is left alone, and `-KeepAccount` opts a new one out. The new `shared-folder` step makes
`C:\Users\Public\atrium`, `/Users/Shared/atrium` or `/srv/atrium`, or prints the command for an administrator, and
`room-git.ps1 init -GitRoot` clones under it. `-Check` runs both steps read only. New verbs `atrium room set git_root
<path>` and `atrium room get git_root` write and read the room's `git_root` setting in its database. They refuse a
database a running room holds, and `set` makes the database when the room has never run. Provisioning calls `room set`
over ssh after the join, so a new machine's room looks for its clones in the shared folder.
