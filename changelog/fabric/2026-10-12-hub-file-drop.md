# A hub file drop

A card on any room can now hand a file to a card on any other room through the hub, with `atrium_put`, `atrium_files`,
`atrium_get` and `atrium_export`. Files keep 7 days by default, are capped at 32 MiB each and 512 MiB in all, and show
on a new Files tab of the board and a files sheet on the phone, where they can be downloaded, uploaded and deleted
(f-hub-file-drop).
