A Windows room provisioned by `provision-room.ps1` now gets go (the go.mod version), Git for Windows with its bash, pwsh and node, so a worker on it can build atrium and run the tests. sgg had MinGit and no go, no bash. The new `toolchain` step runs `room-toolchain.ps1`, which now counts a git with no bash beside it (MinGit) as missing and installs PortableGit. The room reads PATH once, so a room already up needs `atrium stop` and a start. `-NoToolchain` skips the step.
