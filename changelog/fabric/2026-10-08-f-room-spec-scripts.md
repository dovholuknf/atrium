`provision-room.ps1` and `room-check.ps1` no longer set up the work root, the tool caches or the agent pack themselves: they write a `room.yaml` and run the room's own `atrium room setup --plan` before a change and `--apply` after the join, and print its rows. `scripts/room-work.ps1` is gone, `scripts/room-spec.ps1` is the little that is left, and a refused spec now says why on stderr instead of exiting 1 in silence. A run with no `-WorkRoot` keeps the shared folder and still installs the agent pack, from a `room.yaml` of the pack alone. The agent pack goes to every runner the repository has one for (claude, and codex or gemini when their folders hold agents or skills), and `CODEX_HOME` and `GEMINI_CLI_HOME` in the account's environment are followed. A bad `-WorkRoot` is refused before ssh by this machine's own `atrium room setup --validate`, and a failed pack is a warn, never an exit code. (f-room-spec)
