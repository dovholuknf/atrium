`provision-room.ps1` and `room-check.ps1` no longer set up the work root, the tool caches or the agent pack themselves: they write a `room.yaml` and run the room's own `atrium room setup --plan` before a change and `--apply` after the join, and print its rows. `scripts/room-work.ps1` is gone, `scripts/room-spec.ps1` is the little that is left, and a refused spec now says why on stderr instead of exiting 1 in silence. A run with no `-WorkRoot` keeps the shared folder and installs no agent pack. (f-room-spec)
