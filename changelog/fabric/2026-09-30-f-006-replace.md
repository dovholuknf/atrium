The Go permission gate now replaces the dotfiles gate instead of standing aside. A registered `atrium-perm-hook`
command reads as the gate installed but stale, and install all or installing the row by name rewrites it in place as
`atrium hook --event permission`, keeping its matcher and timeout. With both registered, install removes the script and
keeps atrium's. sg4's own settings now run the Go gate. (f-006)
