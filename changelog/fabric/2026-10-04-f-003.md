Agents can now look up the machines and environments they may use. A new worker tool, `atrium_resources`, returns
`resources.md` from atrium's state dir (`~/.atrium/resources.md` on a default room) together with the rooms the hub
knows and whether each is online. clint edits the file by hand, one `## <name>` entry each, and no agent writes it.
`atrium resources init` writes a starter file with a header that says names and commands only, never a token, password or
key, and it never overwrites a file that is there. Every launched card's brief, or its prompt when it has no brief, now
carries one line naming the tool. Stage 1 reads the file on the hub's machine, and a per-room fan-out and a reachability
probe are stage 2.
