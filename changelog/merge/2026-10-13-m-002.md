- **`scripts/test-touched.sh` tests what a branch touched, and the whole board suite waits for landing.** It runs the
  changed Go packages (with `-tags integration` only when an integration file changed), the headless units read off
  the code for each changed board file plus bootClean, and the node tests whose subject changed, saying why it picked
  each. `check-board.sh`, `test-board-headless.js` and `test-board-sharded.js` refuse a full run without
  `FULL_SUITE=1`, which CI, `make check` and `merge-check.ps1` set. (m-002)
