Clicking a "joined" row in the terminals list now opens a dialog instead of doing nothing. It says the session runs in a terminal atrium does not hold and offers "message it" (the existing message call, queued) and "details" (the card's detail view). "End it" and "take it over" are drawn grey with the reason, because ending needs a terminal atrium holds and resuming a still-running session would run it twice (u-joined-click).
