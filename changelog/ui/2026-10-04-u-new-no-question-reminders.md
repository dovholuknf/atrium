# Growler reminders are a setting per reason

The hub re-raises a permission request on its backoff and rings a question once, never again, and the settings dialog now has a row for it. Under notifications, "growler reminders (on the hub)" has a box for permission requests (on by default) and one for questions (off by default). It saves the moment it is ticked and the hub keeps it, so every board follows it. A board with no hub draws no row. A card that has ended or exited takes its growlers with it.
