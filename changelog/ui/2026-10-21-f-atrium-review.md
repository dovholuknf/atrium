A card started with `atrium launch --kind review --base <branch>` (or `atrium_launch` with `kind: review`) is an atrium review: the agent files findings with the new `atrium_review` tool, the room works out each diff, and the chat tab shows them in a read-only review view beside chat and terminal. A rail lists the findings by category, title and state, the diff is red and green, and the agent's two footer lines are shown verbatim. The route is `/v1/tasks/{id}/atrium-review`, because `/v1/tasks/{id}/review` is already the pull request review. (f-atrium-review)
