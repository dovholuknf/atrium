# The phone can approve on a hub with two rooms, and three smaller phone fixes

With two rooms attached the phone could not approve or deny anything: its answer carried no room, and the hub routes a
permission path by the room header alone, so every row said "Not sent". The phone now splits the room and the bare id
off a tagged request and sends the answer with `X-Atrium-Room`. The desktop board had the same fault in the all-rooms
view and sends the header on a hub now.

The phone composer reads each card's own room for whether its runner takes a bracketed paste, so two rooms' `claude`
rows no longer overwrite each other. A card or a removal that arrives while the list is being read is no longer undone
by that read's older answer. A tap on a card while the sheet is still sliding out now opens it.
