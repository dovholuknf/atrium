# Board-wide auto no longer rings for a request it approves

With board-wide auto on, a permission request now waits three seconds on the board before it rings, toasts, growls or posts a desktop notification. The hub approves a pending request within a moment, so almost every one is gone before the wait ends and nothing is said. A request still pending when the wait ends rings as it always did, and with auto off nothing waits. The same wait holds in a popped-out card's window. A request whose body is a JSON payload, such as a subagent handback, now shows its message or first field in the tray line and the notification, not escaped JSON cut at 120 characters.
