# The card details show a dash, not 0, for a count the room did not send

Hovering a card could show a context figure with the meter filled and PROMPTS, CALLS, UNCACHED IN, OUT, CACHE READ and CACHE WRITE all 0. A count the room's answer did not carry was drawn as 0, which reads as a real zero. Those cells now show a dash with the tip "not reported by this room", and a count the room did report as 0 still shows 0. The hub relays a room's usage answer whole for a `room~id` card (a test now holds it to that).
