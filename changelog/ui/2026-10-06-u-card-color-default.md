# Cards are plain until you colour them

A card nobody coloured now wears the skin's plain card look instead of the atrium green. Settings has a new
`card colours` section with a default colour, a list of colours by repo, and a preview card that wears your pick
before you save it.

- Repo colours key on `provider/org/repo`, for example `github/openziti/ziti`. A worktree, branch or title never
  changes the colour, and the same name on two providers no longer shares one.
- Add a repo from the ones the board already knows. Colours are kept in this browser and shared by every tab.
- The built-in entries keyed by repo name alone still apply, but only when no full key matches the card.
- Cards only wear colour with `board cards wear their terminal colours` on.
