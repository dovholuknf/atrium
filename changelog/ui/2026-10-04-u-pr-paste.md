# Paste a pull request link and get a worktree

Pasting a github or bitbucket pull request link on the board opens the launch dialog filled in. Pressing launch now makes the PR's worktree first, on its real branch (`pr-<N>` for a fork), and starts the card in it. On a hub with no room chosen, the PR goes to the room that already holds it or else the least busy one, and the card starts on that same room. A refusal from the forge shows as its own sentence and starts nothing. A directory you typed over is left alone.
