Closing a card is one dialog. The summary lists what is freed with each worktree's real size, ignored folders such as node_modules included, and a worktree holding work nowhere else is a row in it with keep, stash (preselected) and delete inline. Pressing close keeps the dialog up and names each step as it runs, stopping the session, processes, ports, review, each worktree, branches and refs, ticking each off or showing what git said. The dialog shuts itself when done and stays open on a failed step, and the card reads "closing" meanwhile. The leftovers sweep's close works the same way. (u-close-one-dialog, u-close-progress)
