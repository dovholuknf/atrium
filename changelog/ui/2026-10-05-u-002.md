# A row kept by `hide inactive agents` is no longer drawn grey

With `hide inactive: agents` on, an exited row can still be listed: the card open in the pane is never hidden, and a click on a grey row to start it again makes it the open one. That row used to be drawn grey like the rows the filter hides, so a grey row and a hidden row were not the same answer. It is now drawn at full strength with an `attached` chip (`opening` while it starts), and its tooltip says hide inactive keeps it listed because it is open. Grey still means an exited row with the filter off. Every other exited row, pinned or not, is hidden as before. The `? 2` chip on an exited card no longer says it clears when you reply, since nothing can reply to it. It says to click to dismiss.
