A `walk` button on the terminal bar opens a drawer beside the terminal when the card's directory holds a `findings/` folder.
It lists the findings in order, shows the code from `pr.diff`, and lets you ask the walker, edit, copy, open, mark posted or skipped.
Walk state is a `Walk:` line in each finding file, and edits are refused with a compare if the file changed under you.
Nothing is posted to GitHub. (u-005)
